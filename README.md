# 🍔 Burger Forge ⚒️

Uma aplicação web desenvolvida para praticar os principais métodos de manipulação de arrays em JavaScript: ForEach, Map, Filter e Reduce,
além da construção de uma interface responsiva utilizando Flexbox, CSS Grid e Glassmorphism.

## ✨ Funcionalidades

### 👀 Mostrar Tudo
Exibe todos os hambúrgueres disponíveis utilizando o método `forEach()`.

### 🗺️ Aplicar Desconto
Aplica 10% de desconto em todos os produtos utilizando `map()`.

### ➕ Somar Tudo
Calcula o valor total dos produtos utilizando `reduce()`.

### 🔍 Filtrar Veganos
Exibe apenas os hambúrgueres veganos utilizando `filter()`.
